# pablo-backend
This is the Node.js to my card game called Pablo

# src Folders

- routes: These are the specific maps from URLs to controller functions
- controllers: Handles the HTTP request and response
- middleware: Holds any code that runs before the controllers
- models: These define the data layer
- services: This is the business logic between controllers and models
- sockets: WebSocket/Socket.IO event handlers
- game: The rules engine
- config: env vars, DB, and Redit setup
- types: shared types
